# 提现自动审核新增充值成功率_261102

## 一、需求目标

在「订单管理 → 提现自动审核配置」中新增「充值成功率」阈值。当用户充值成功率小于或等于配置值时，转人工审核。

## 二、原型地址

[提现自动审核配置可视化原型](https://hdddong.github.io/LUCKY/admin/#menu=m5-6)

进入页面后点击「新增」或「编辑」查看配置。

## 三、字段配置

| 项目 | 说明 |
|---|---|
| 字段名称 | 充值成功率 |
| 位置 | 新增、编辑弹窗中，位于「审核标签」上方 |
| 控件 | 数字输入框，右侧固定显示 `%` |
| 输入范围 | 0～100，包含 0 和 100，支持两位小数 |
| 必填 | 否；新增时默认留空，留空不启用此项审核条件 |
| 提示 | 充值成功率小于等于配置值时，转人工审核。 |

- 字段名称右侧显示灰色实底问号，悬停展示提示。
- 配置列表增加「充值成功率」列，带 `%` 展示。
- 编辑时回填已保存阈值；复制配置时一并复制该字段。

## 四、审核规则与校验

- 触发条件：**用户充值成功率 ≤ 配置阈值**，转人工审核。
- 示例：配置 `50%` 时，用户成功率为 `49%` 或 `50%` 均触发；`51%` 不触发本项规则。
- 未触发本项规则不代表自动通过，仍按其他审核条件处理。
- 留空允许保存，不启用充值成功率审核条件；列表显示「—」。填写后校验数字格式、0～100范围及最多两位小数，不符合时提示并阻止保存。
- 充值成功率的统计时间范围、计算分母及无充值记录时的处理口径待确认，本次不新增计算口径。

## 五、验收标准

1. 新增、编辑弹窗均显示该字段。
2. 输入 `50` 保存后，列表显示 `50%`；再次编辑正确回填，复制到目标包后阈值一致。
3. 留空、`0`、`100`、`25.5`、`25.55` 可保存；负数、大于100或超过两位小数不可保存。留空不启用本项规则，`0` 表示启用且阈值为0%。
4. 阈值为50%时，等于50%须转人工审核；高于50%不触发本项规则。
