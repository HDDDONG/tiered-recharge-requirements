# 提现自动审核转人工TG告警_261102

## 一、需求目标

提现订单因不满足自动审核通过规则而转入人工审核时，向指定的 TG 告警群发送一条消息，展示用户、提现时间、提现金额及具体转人工原因。

本次补充告警通知，不改变现有自动审核规则、阈值和人工审核流程。

## 二、关联配置地址

[提现自动审核配置可视化原型](https://hdddong.github.io/LUCKY/admin/#menu=m5-6)

关联入口：订单管理 → 提现自动审核配置。该链接用于查看审核条件配置；本需求新增的是后台告警通知。

## 三、触发规则

1. 提现订单完成自动审核，因命中一项或多项转人工规则，实际进入人工审核时，发送告警。
2. 自动审核通过的订单不发送本类告警；未启用或未命中的审核项不列入原因。
3. 同一笔提现命中多项规则时，合并为一条消息，原因逐条换行展示。
4. 同一订单的同一次转人工事件只发送一条告警，重复回调、重复消费不重复发送；同一用户的不同提现订单分别发送。
5. 告警发送失败不阻断订单转人工。保留发送结果并支持失败重试，重试沿用同一事件标识。
6. 发送到业务指定的 TG 告警群，群及机器人使用部署配置，不在本次需求中新增后台配置菜单。

## 四、消息格式

```text
提现未通过自动审核
用户ID：{用户ID}
提现时间：{YYYY-MM-DD HH:mm:ss}
提现金额：{提现金额}
原因：
1. {原因1}
2. {原因2}
```

| 字段 | 说明 |
|---|---|
| 标题 | 固定为「提现未通过自动审核」 |
| 用户ID | 本笔提现订单所属用户的ID |
| 提现时间 | 提现订单的申请时间，精确到秒；时区与后台提现订单列表一致，不使用告警发送时间 |
| 提现金额 | 本笔订单的申请提现金额；金额精度和币种展示沿用提现订单口径 |
| 原因 | 本次自动审核实际返回的转人工原因；只有一项时仅展示一条，多项时按下表顺序展示 |

原因中的占位符替换为本次审核使用的配置值或实际命中内容。不得直接发送 `{0}` 等占位符，也不得只写「不符合规则」「不符合充值成功率」等笼统描述。

### 原因枚举

| 审核项 | 原因消息模板 | 参数说明 |
|---|---|---|
| 首次提现审核 | 首次提现，需人工审核 | 首次提现审核开启，且本笔订单符合现有首次提现判定 |
| 套利游戏 | 套利游戏占比大于 {0} | `{0}` 为套利游戏配置阈值；单位沿用现有审核口径，不擅自转换为百分比 |
| 打码倍数 | 打码倍数小于 {0} 倍 | `{0}` 为配置的打码倍数阈值 |
| 关联账号数量 | 关联账号数量大于 {0} 个 | `{0}` 为配置的关联账号数量阈值 |
| 关联账号平均打码倍数 | 关联账号平均打码倍数小于 {0} 倍 | `{0}` 为配置的平均打码倍数阈值 |
| 可疑充值金额 | 命中可疑充值金额：{0} | `{0}` 为实际命中的可疑充值金额；多个金额用「、」分隔，仅展示命中项 |
| 当日提现次数 | 当日提现次数大于 {0} 次 | `{0}` 为配置的当日提现次数阈值 |
| 当日提现失败次数 | 当日提现失败次数大于 {0} 次 | `{0}` 为配置的当日提现失败次数阈值 |
| 单笔提现金额 | 单笔提现金额大于 {0} | `{0}` 为配置的单笔提现金额阈值 |
| 审核标签 | 命中审核标签：{0} | `{0}` 为实际命中的审核标签；多个标签用「、」分隔 |
| 贡献值 | 贡献值位于 [{0}, {1})，综合提现率大于 {2}% | `{0}` 为命中区间下限，`{1}` 为上限，`{2}` 为该区间配置的综合提现率；包含下限、不含上限 |
| 充值成功率 | 充值成功率小于等于 {0}% | `{0}` 为配置的充值成功率阈值；字段留空时不启用本项规则 |

原因使用本次审核结果及当时的配置值生成，发送或重试时不重新读取最新阈值改写历史原因。各项统计、匹配和判定口径沿用现有审核逻辑，告警模块不自行推导。

### 消息示例

```text
提现未通过自动审核
用户ID：12345678
提现时间：2026-11-02 14:30:05
提现金额：₹1,000.00
原因：
1. 当日提现次数大于 3 次
2. 充值成功率小于等于 50%
```

## 五、验收标准

1. 订单因审核规则转人工后，指定 TG 群收到一条消息，标题及字段顺序符合约定。
2. 用户ID、申请时间和提现金额与对应订单一致，时间展示到秒。
3. 命中单项规则时展示对应具体原因；命中多项规则时，同一条消息列出全部已判定的命中原因，不拆分发送。
4. 阈值为50%时，实际充值成功率等于或低于50%且因此转人工，原因展示「充值成功率小于等于 50%」；高于50%不生成该项原因。
5. 充值成功率未配置时，不生成该项原因；其他关闭或未命中的规则同样不展示。
6. 标签、可疑充值金额只展示实际命中项，贡献值原因展示命中区间及对应比例。
7. 自动审核通过不发送告警；同一转人工事件重复处理不重复通知；不同订单分别通知。
8. TG 发送失败时订单仍正常进入人工审核；重试不改写原审核原因、不产生重复告警。

## 六、接入信息

上线前提供目标 TG 群标识及可向该群发消息的机器人配置。机器人凭证通过部署配置管理，不写入需求文档或告警消息。
