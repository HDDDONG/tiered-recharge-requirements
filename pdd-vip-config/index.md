# PDD活动VIP分组配置_261102

## 一、需求目标

在活动管理的 PDD（拼多多转盘）配置页增加多配置结构，按 VIP 等级范围维护各自独立的活动配置。

## 二、原型地址

[PDD活动配置可视化原型](https://hdddong.github.io/LUCKY/admin/#menu=m11-7-1&activity=24&view=rules)

链接直接进入 PDD 活动配置页。

## 三、配置结构

1. 在页面顶部、参与配置上方显示「配置一」「配置二」等标签，按新增顺序命名。
2. 默认展示一份「配置一」，原有活动配置归入该配置。
3. 标签区提供「＋ 新增配置」按钮。点击后新增一份独立配置，并切换到新配置。
4. 每份配置顶部增加「VIP等级」范围输入：下限【 】至上限【 】。
5. 每份配置均包含下方全部配置模块，数据分别维护，不共用或覆盖其他配置。

| 层级 | 内容 |
|---|---|
| PDD活动 | 包含一份或多份配置 |
| 配置一、配置二…… | 各自维护 VIP 等级范围 |
| 每份配置内部 | 参与配置、自动审核（自动通过、自动拒绝）、奖励配置、首次奖励配置（显示用）、转盘配置、浮动值基础值配置、附加值配置、任务配置、游戏规则 |

## 四、交互与保存

- VIP 等级上下限必填，使用非负整数，下限不能大于上限。
- 切换配置标签时保留当前输入，再展示目标配置的数据。
- 任一配置内的输入、档位增删、spin 次数调整和游戏规则修改，只作用于该配置。
- 点击「保存配置」时统一校验并保存全部配置，包括当前未展示的配置。
- 某份配置校验失败时，切换至该配置并显示对应提示，不保存本次修改。
- 再次进入配置页时，完整回填所有配置及其 VIP 等级范围。
- 「重置」恢复进入页面时的全部配置，移除本次尚未保存的新增配置，并返回配置一。

## 五、验收标准

1. 新增配置后，可通过「配置一、配置二……」标签切换。
2. 每份配置都有 VIP 等级范围和完整的下层配置内容。
3. 在配置一、配置二填写不同内容，往返切换后各自数据不变。
4. 保存后重新进入，各份配置的数量、VIP 范围及内容正确回填。
5. 非当前配置的 VIP 范围填写错误时，保存须定位该配置并提示。
