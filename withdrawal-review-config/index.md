# 提现自动审核配置（261028）

更新日期：2026-10-28。

## 需求范围

后台：订单管理 → 提现自动审核配置。

新增「提现自动审核配置」菜单，与「提现订单」同级，位于其下方。按包ID维护提现审核条件，支持查询、新增、编辑及跨包复制。

## 原型地址

[提现自动审核配置可视化原型](https://hdddong.github.io/LUCKY/admin/#menu=m5-6)

## 页面流程

1. 进入菜单后展示提现配置表。
2. 使用包ID、生效状态筛选配置，点击「查询」刷新结果；「重置」清空包ID并恢复全部状态。
3. 点击表格左上角「＋ 新增」，打开新增弹窗。
4. 点击操作列「编辑」，打开弹窗并回填该配置。
5. 点击操作列「复制」，选择目标appid后批量复制。
6. 保存成功后关闭弹窗并刷新列表；关闭或取消不保存未提交内容。

## 配置列表

### 筛选条件

| 字段 | 控件 | 规则 |
|---|---|---|
| 包ID | 输入框 | 按包ID查询；多包配置包含该包ID时可被查出 |
| 生效状态 | 下拉单选 | 全部、开启、关闭；默认全部 |

两项筛选条件同时使用时取交集，无匹配结果时展示空状态。

### 表格字段

| 顺序 | 字段 | 展示内容 |
|---:|---|---|
| 1 | 包ID | 配置关联的包ID，支持展示多个 |
| 2 | 首次提现审核 | 是／否 |
| 3 | 套利游戏 | 数字阈值 |
| 4 | 打码倍数 | 数字阈值 |
| 5 | 关联账号数量 | 整数阈值 |
| 6 | 关联账号平均打码倍数 | 数字阈值 |
| 7 | 可疑充值金额 | 多个金额用英文分号 `;` 分隔 |
| 8 | 当日提现次数 | 整数阈值 |
| 9 | 当日提现失败次数 | 整数阈值 |
| 10 | 单笔提现金额 | 金额阈值 |
| 11 | 审核标签 | 已选标签，支持多个 |
| 12 | 贡献值 | 是／否，表示是否启用贡献值审核 |
| 13 | 贡献值区间 | 每个贡献值区间与综合提现率成组展示 |
| 14 | 配置生效状态 | 开启／关闭 |
| 15 | 操作 | 平铺「编辑」「复制」按钮 |

- 表格撑满内容区域，超出可视宽度时横向滚动。
- 操作列不固定，随表格横向滚动。
- 贡献值区间展示示例：`[0-10)，20%；[10-100)，20%`。
- 页面底部展示结果条数。

## 新增与编辑

使用统一弹窗样式，标签位于控件上方，普通字段按列排列；可疑充值金额、审核标签和贡献值区间使用整行布局。

### 字段配置

| 字段 | 控件 | 配置规则 |
|---|---|---|
| 包ID | 可搜索下拉多选 | 选择一个或多个包ID；支持搜索、勾选、取消勾选和已选项回填 |
| 首次提现审核 | 滑动开关 | 开启对应列表「是」，关闭对应列表「否」 |
| 套利游戏 | 数字输入 | 填写阈值，不填写游戏名称 |
| 打码倍数 | 数字输入 | 填写打码倍数阈值 |
| 关联账号数量 | 整数输入 | 填写账号数量阈值 |
| 关联账号平均打码倍数 | 数字输入 | 填写平均打码倍数阈值 |
| 可疑充值金额 | 文本输入 | 支持多个数字金额，使用英文分号 `;` 分隔，如 `500;1000;2000` |
| 当日提现次数 | 整数输入 | 填写当日提现次数阈值 |
| 当日提现失败次数 | 整数输入 | 填写当日提现失败次数阈值 |
| 单笔提现金额 | 数字输入 | 填写单笔提现金额阈值 |
| 审核标签 | 可搜索下拉多选 | 从标签选项中选择多个；搜索不清除已选项 |
| 贡献值 | 滑动开关 | 控制贡献值区间规则是否启用 |
| 贡献值区间 | 多行组合输入 | 每行为「下限、至、上限、综合提现率」；支持添加和删除 |
| 配置生效状态 | 滑动开关 | 开启时配置参与审核；关闭时不应用该配置，保留配置内容 |

包ID和审核标签选项使用相应业务数据源，不将展示用选项固定为业务枚举。

### 贡献值区间

每行维护一组贡献值区间与综合提现率，综合提现率输入框右侧显示 `%`。

| 贡献值下限（含） | 贡献值上限（不含） | 综合提现率 |
|---:|---:|---:|
| 0 | 10 | 20% |
| 10 | 100 | 20% |

- 区间匹配方式：**下限 ≤ 用户贡献值 < 上限**。
- 区间允许跳开，不要求连续。例如 `[0-10)` 与 `[20-100)` 可保存；落在空档的贡献值不触发该贡献值规则。
- 区间不可重叠，与填写顺序及综合提现率是否相同无关。`[0-10)` 与 `[10-100)` 首尾相接，不属于重叠。
- 比例输入 `20` 表示 `20%`；区间与比例作为一组保存，不拆成互不关联的值。
- 用户贡献值命中区间，且综合提现率**大于**该组配置比例时，转人工审核；等于比例时不触发该组规则。
- 贡献值为 `10` 时，命中 `[10-100)`，不命中 `[0-10)`。
- 开启贡献值时，区间可填写，添加和删除按钮可操作。
- 关闭贡献值时，下限、上限、综合提现率输入框及添加、删除按钮均禁用；区间不参与审核，也不要求填写。
- 关闭开关不清空已有配置，重新开启时恢复显示；取消弹窗不改变已保存内容。

### 保存校验

- 包ID至少选择一项。
- 数字字段不得填写非数字或负数；数量、次数使用整数。
- 多个可疑充值金额逐项校验，分隔符为英文分号 `;`。
- 贡献值开启时，每组下限、上限、综合提现率必须完整，下限必须小于上限，比例为非负数字。
- 保存时检查所有贡献值区间，包含、重复或部分交叉均视为重叠；发现重叠时阻止保存，保留弹窗及已填写内容，页面提示「贡献值区间第 X 行与第 Y 行重叠，请调整后保存。」；调整后再次保存并重新校验。
- 贡献值关闭时，跳过区间必填、有效性及重叠校验，保留原已保存的区间配置。
- 校验失败时显示对应错误，不保存；保存成功后再次编辑须完整回填多选项、开关、阈值和区间配置。

## 字段提示

有提示的字段在名称右侧显示灰色实底圆形问号，与文字垂直居中；鼠标悬停显示说明，移开关闭。支持键盘聚焦查看，按 Esc 关闭。表头和编辑控件使用一致的说明。

| 字段 | 提示说明 |
|---|---|
| 套利游戏 | 用户打码量 / 总打码量大于套利游戏阈值时触发。 |
| 打码倍数 | 用户的打码倍数小于阈值时触发。 |
| 关联账号数量 | 关联账号数量大于配置值时触发。 |
| 关联账号平均打码倍数 | 关联账号中的平均打码倍数小于阈值时触发。 |
| 可疑充值金额 | 输入多个金额时，使用英文分号「;」分隔。 |
| 当日提现次数 | 用户单日提现次数大于阈值时触发。 |
| 当日提现失败次数 | 当日提现失败次数大于阈值时触发。 |
| 单笔提现金额 | 单笔提现金额大于阈值时触发。 |
| 审核标签 | 用户有配置的标签时，转人工审核。 |
| 贡献值 | 选择「是」时，按配置的贡献值区间和综合提现率判断。 |
| 贡献值区间 | 每组由贡献值区间和综合提现率组成；命中区间且综合提现率大于该组比例时，转人工审核。 |

## 复制配置

复制使用独立小弹窗，不展开完整配置表单。

### 弹窗内容

1. 源appid：只读显示源配置关联的appid。
2. 「复制到」提示。
3. 目标appid：可搜索下拉多选，支持勾选多个目标，显示已选项；不使用折叠面板样式。
4. 「确定」按钮和右上角关闭按钮。

### 复制规则

- 至少选择一个目标appid；源配置已有的appid不作为复制目标。
- 点击「确定」后，将源配置的审核条件、标签、贡献值区间、各开关和生效状态复制到所选目标。
- 目标appid保持为目标值，不被源appid替换。
- 目标已有配置时覆盖目标配置；无配置时建立目标配置。
- 复制不改变源配置，不影响未选中的包；目标属于多包配置时，未选中的其他包保留原配置。
- 关闭弹窗或取消选择不执行复制。
- 复制完成后刷新列表，并反馈处理的目标数量。

## 审核规则边界

- 「配置生效状态」控制整份配置是否应用；「首次提现审核」和「贡献值」分别控制对应审核项。
- 各阈值的比较方向按字段提示执行，严格区分「大于」「小于」与「等于」。
- 配置关闭或某项未触发，不等同于提现自动通过；仍须执行其他适用的提现审核规则。

以下口径在实现审核引擎前需明确，不由页面示例值推导：

- 首次提现的判定口径，以及关联账号、有效打码量、贡献值和综合提现率的数据计算口径。
- 套利游戏占比的分子范围、数值单位，以及总打码量为零时的处理。
- 当日次数统计的时区、订单状态范围；可疑充值金额匹配的订单范围。
- 多份配置覆盖同一包时的优先级。

## 验收标准

1. 菜单位于订单管理下、提现订单之后，进入即展示配置列表。
2. 表格按约定顺序展示15列，操作按钮平铺且不固定。
3. 包ID、生效状态可分别或组合查询；多包配置能通过其中任意包ID查出，重置恢复全部结果。
4. 「＋ 新增」位于筛选区下方、表格左上角。
5. 新增和编辑的包ID、审核标签均为可搜索下拉多选；搜索、清空搜索和取消勾选均不丢失其他已选项。
6. 三个布尔配置使用滑动开关；首次提现审核、贡献值在列表显示「是／否」，配置生效状态显示「开启／关闭」。
7. 套利游戏保存数字；可疑充值金额支持以英文分号分隔的多个金额。
8. 贡献值区间逐行输入上下限和比例，可添加、删除，并正确保存、回填及成组展示。
9. 关闭贡献值时，区间输入和增删按钮禁用，空区间不阻止保存；重新开启后恢复可编辑。
10. 按 `[0-10)，20%；[10-100)，30%` 配置时，贡献值10、综合提现率25%不触发第二组；综合提现率31%触发第二组。
11. 保存校验失败不改变原配置；关闭或取消弹窗不保存。
12. 复制弹窗只显示源appid、目标多选及确认操作；多目标复制正确保留目标appid与源配置，未选包不受影响。
13. 字段右侧问号悬停和键盘聚焦可查看提示；列表及弹窗不展示示例说明、会话保存说明。

14. `[0-10)` 与 `[20-100)` 可保存；`[0-10)` 与 `[10-100)` 可保存；`[0-20)` 与 `[10-100)` 保存失败并提示冲突行。重复区间、包含关系及乱序输入同样校验，修改为不重叠后可保存。
